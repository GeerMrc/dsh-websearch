## 踩坑 / 经验

- **同版本 file: tarball 换包陷阱**：dep 字符串未变时 pnpm install 不刷新内容——必须删除 node_modules 内条目（或换 tarball 文件名）强制重装；验证手段 = md5 对比仓库与安装位 client.js。
- **i18n parity 门禁不查语义**（S21 教训类第 2 次现形）：改 fan-out 面不改 ⓘ 文案 = 文档与实现矛盾；语言面变更须逐条核 locales 提示文案。
- **IAB 键盘手势假阴性**：`Meta+a` 在 IAB 可能不全选，「清空失败」实为守卫正确拒绝半编辑值；探针用原生事件派发（setter+input event）才能测到真实清空路径。
- **探针前 key 可得性探查**：硬规则（探针不可得 ⇒ 不实现）要先穷尽 env/DSH_HOME/.env/插件目录四层再落结论。
