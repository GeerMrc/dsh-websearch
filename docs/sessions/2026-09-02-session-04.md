## 踩坑 / 经验

- **坑（快解，同棒修复）**：验证命令输出用 `tail -1` 截断，lint 的 warnings 汇总行被吃掉——首跑门墙带着 2 warnings 进了台账初稿（0w0e 误写）。修复后台账留痕修正说明。教训：门墙数字必须来自完整输出的过滤视图（grep 全文），不截断尾部
- **坑（快解）**：pnpm install 会自动向 pnpm-workspace.yaml 追加 minimumReleaseAgeExclude 条目——只提交 package.json + lockfile 会留脏工作区（阶段 4/5 F-1 抓获）。教训：依赖变更类任务 commit 前必须 `git status` 全查，install 的副作用文件属同一变更语义
- **经验**：fake credentials + fake event bus（on 捕发）组合可把「写 ref→事件→available 翻转」整链测进单测，无需真实宿主——热刷新验收面从「集成假设」变「单测事实」；vi.waitFor 兜底异步刷新时序
- **经验**：apply 内 ref 预校验（同步 credentialRef）先于任何注册——把 misconfiguration 从异步 rejected promise 提升为 load 期同步 fail-loud；fire-and-forget 的 prime catch 只防意外 bug 变 unhandled rejection，不是错误处理路径（注释已写明）
- **经验**：published dsh-credentials（alpha.4）类型面（CredentialProvider/CredentialInfo/CredentialRef + ctx 增强）与 vendored alpha.3 源一致，typecheck 一次通过——上游 published 类型增强路线（S03 dsh-web 先例）可复用
