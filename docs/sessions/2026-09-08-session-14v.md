## 踩坑 / 经验

- **坑（链式命令吞失败）**：`cmd1 > /dev/null; echo $?` 后接 `&& git commit`——echo
  恒成功，typecheck exit 2 照常走到提交。**门禁命令必须独立判定 exit 再门控提交**（本
  棒红线 1 次，与 14u「只读 Tests 行」同族：输出读半截/失败被吞）。
- **经验（取证先于定性）**：三类报错两类非插件——盘上 session 日志逐条 verbatim + DNS
  对照实测（fake-ip 二分）+ 宿主防护源码三件证据齐了才下结论；「DDG 202 反爬」若只看
  报错文案（parsed no results）会误判为解析 bug 而去修解析器。
- **经验（不可修也要修得诚实）**：出口 IP 被 DDG 封锁无法在插件侧解决，但误导性报错
  可以修——「不可修复的问题也要报得让人看得懂」本身是交付物。
