## 踩坑 / 经验

- **迁移类工作的闭环拆分**：端点 URL 改动会连带下游夹具（loopback arrival 断言）——URL 面必须与请求面同 commit，响应形状面可与 mapper 同 commit 分步走；plan 阶段就把夹具涉及面查实（「若涉」假设式措辞会被审核打回）。
- **lint 装饰性修复晚于发版工件**：修复后 tarball 已装——行为等价可披露不重装（同版本号重装会被 pnpm 跳过，需 rm node_modules，不值当）；阶段 4 逐行为核实等价性背书。
- **Agent API 调研要点**：web_search 是 opt-in（搜索成员必须恒含工具——否则静默变成纯参数记忆作答，最难察觉的回归）；模型名要 provider/ 前缀（存量配置在 provider 侧归一即可兑现零改动承诺）。
