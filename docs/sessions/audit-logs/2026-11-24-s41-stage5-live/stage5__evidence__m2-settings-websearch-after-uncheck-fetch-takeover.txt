  - list:
    - strong: 搜索链降级
    - text: ：按你排的顺序逐个尝试。成员没配 key、被停用，或者请求失败、超时，都跳到下一个；全部失败才报错，并给出每个成员的失败原因。
    - strong: 多 key 轮换
    - text: ：一家可以填多把 key。某把失效时，先在同一家换 key 重试，再降级到下一家。
    - strong: 来源标注
    - text: ：每次搜索和抓取的工具行上会标出实际由哪个成员提供服务。
    - strong: DNS 韧性
    - text: ：在解析受限的网络里，自动改用加密解析并预先探测线路；网络正常时不做任何改动。
  - heading "设置项" [level=2]
  - paragraph: 位置：设置 → 网页搜索。修改从下一次搜索起生效。
  - list:
    - strong: 成员卡
    - text: ：为每家填 API key、启停成员、覆盖接口地址、调整该家的搜索参数。
    - strong: 搜索链
    - text: ：调整成员的先后顺序，排在最前的是主搜索。
    - strong: 接管 web_fetch
    - text: ：开启时，网页获取走本插件的云端抓取链；关闭时走本机直接抓取。
    - strong: DNS 韧性
    - text: ：开启、关闭，或保持自动。
    - strong: 详细配置
    - text: ：兜底成员、超时、统一的搜索语言与地区等。
  - paragraph: API key 只保存在你本机的凭据里；页面上只显示每家已配置的 key 数量。
