## 踩坑 / 经验

- **坑（typecheck 管道退出码）**：`pnpm typecheck | tail` 时 `$?` 取的是 tail 的
  0，门墙先漏一处 TS 红（HTMLElement 缺 disabled 收窄）——退出码必须取 pnpm 本体
  或 grep error 计数。
- **坑（截图视口截断，阶段 4/5 抓获）**：720px 首屏截图拍不到下方元素——归档前先
  `scrollIntoView({block:'center'})` 再拍（滚动版补拍清偿）。
- **经验（remove→add 换包）**：同版本 tarball 直接 add 被 pnpm 跳过——remove 后
  add 即可强制重装，无需 rm node_modules。
- **经验（zh 文案首度实机）**：界面语言随浏览器 locale 切中文，40 键 zh 面首次被
  实机亲见（此前全英文环境）。
