## 踩坑 / 经验

- **坑（宿主 chat 是 SSE 流式）**：LLM stub 回普通 JSON → 轮次失败 `STREAM_CLOSED
  （SSE stream ended without [DONE]）`——stub 必须 `text/event-stream` +
  `data: [DONE]` 终止。诊断路径：UI status 行直接给码。
- **坑（workspace 选择器输入不进）**：UI chooser 的复合输入框 fill 报「not an
  input/textarea」、cua.type 空转——正解是**预播种 workspace 注册表**：
  `$DSH_HOME/storages/workspace.json` 直写（id=randomUUID、path 必须 canonical
  `/private/tmp/...`——resolveByPath 走 realpath），重启后侧栏 treeitem 一点即活
  （12m 配方坑 2；**用户中途纠偏指向该既有配方，勿再从零 UI 摸索**）。
- **坑（同会话 tool 历史污染 stub 分支）**：stub 按「messages 含 role=tool 给终答」
  分支，同会话第二轮因历史已含 tool 消息直接终答不再发工具调用——每轮换新会话。
- **坑（locator click 假成功第三次复发）**：T5 展开工具组 locator click 无效果
  （snapshot 无新元素）——evaluate 取 getBoundingClientRect 后 cua 坐标点击立通。
  家族坑已在 T0 入册 dont-do，本棒为入册后首次实证。
- **坑（发布包类型链静默 any）**：type-only import 的 d.ts 经未安装包解析 block →
  skipLibCheck 下 `typecheck 照样 exit 0`——必须垃圾对象探针实证（详见 Agent Note
  §2 与 §7）。通用教训：**外部 host 类型「编译过了」不等于「类型真解析了」**。
- **经验（单 stub 口三形状）**：LLM（/chat/completions SSE）+ 插件 deepseek 成员
  （/messages anthropic，行 config baseURL 指向）+ 宿主内置（DEEPSEEK_SEARCH_BASE_URL
  指向同口）共用一个 3430——三轮 provider 态切换只改 profile patch 标量（live
  reload 即时生效，dump-config 可验）。
- **经验（live reload 切 provider）**：改 scratch profile cordis.patch.yml 的
  searchProvider 标量即时生效（无需重启），dump-config 复验——T1 调研注记 1.5 的
  「patch 层热切」判定在浏览器棒顺手实证。
