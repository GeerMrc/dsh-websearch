## 踩坑 / 经验

- **坑（workspace 播种 storages/ 目录）**：dump-only 流程不创建 `storages/` 目录
  ——heredoc 重定向静默失败（zsh 报 no such file）但链上后续命令照跑，`workspace
  seeded` 回显造成假象。先 `mkdir -p $DSH_HOME/storages` 再写。配方记忆已补。
- **经验（S14 配方一次复用成功）**：SSE stub + workspace canonical 播种 + 每轮新
  会话 + cua 坐标点击四件套按记忆复用，T5 一轮即闭合（S14 曾三轮摸索）——跨会话
  配方沉淀的价值实证。
- **经验（e2e 时序即证明）**：dump-config 三态对照（基线→装→卸）中唯一变量是
  plugin add/remove，无需 provenance 标注即构成装即接管的机制级证据；T6 独立
  重演再叠一层第一手复现。
- **经验（探针守卫双断言）**：fetch 不钉扎的守卫被 T6 探针证明有牙（改钉后两条
