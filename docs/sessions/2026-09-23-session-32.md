## 踩坑 / 经验

1. **跨代 codec 缺陷（本批最重发现）**：T2 矩阵把 strict codec 字段更名判为「纯编译级」——错。旧 client 在**调用时**用 `codec.schema.parse()` 客户端侧解析入参；`create` 单字段在旧宿主=undefined.parse 崩溃→徽标静默消失。修复=双字段并存（各代只读己方字段）。3434 演练抓获+TDD 修复+复验。
2. **volatile 包装发生在 schema 调用（插件侧 schemastery）**：与宿主版本无关——旧宿主 GUI 若拿 handle 会序列化成空对象 → 双 schema 工厂（ConfigLegacy 无标注版供 installSection）。
3. **pnpm 11.7 供应链策略三坑**：默认 minimumReleaseAge=24h（config list 看不见）；命中自动追加 exclude；依赖变更后 lockfile 校验不读 exclude → 处方 `pnpm clean --lockfile && pnpm install` + verifyDepsBeforeRun=false。
4. **证据勿落 /tmp**（阶段 5 抓获）：B 线 BLOCKED 结论的原始证据曾在 /tmp——与 C3 死 tgz 同类风险；已入库。
5. `pnpm install | tail; echo $?` 取到的是 tail 的退出码（假绿）——验收数字必须无管道亲取。
6. IAB 菜单点击假成功（先例 dont-do 复现）——改 headless/链日志证据路径更可靠。
