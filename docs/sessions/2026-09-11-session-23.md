## 踩坑 / 经验

- **单文件 CJS 插件无 CSS 通道**：伪类样式唯一通路 = 注入式 `<style>` + data-* 属性选择器（token 化）；Input 等 CSS-module 原语的 wrap 无法被调用方布局接管（className 只追加 module 类）。
- **条件挂载与卡级状态的语义矛盾**：折叠头 dirty pill 必须以「draft 提升到不卸载层级」为前提，否则 pill 语义不成立（B2 教训）。
- **差距审计产出两种「方言」并存的宿主**：对齐前先锚定一种（本批锚 Models rowCard），否则 13/18 项会来回摇摆。
