## 踩坑 / 经验

- **坑（vitest 门墙口径）**：`grep "Tests "` 只看通过数会漏 `Errors 1 error` 与 exit
  code——T4 新测试 promise 创建后先 advance 后挂 handler，rejection 在窗口内裸露成
  Unhandled Rejection，315 passed 仍 exit 1。**门墙口径 = exit code + Tests 行 +
  Errors 行三件**（复发红线：这是第 N 次「输出读半截」）。
- **坑（e2e 钉尾要钉到端口）**：钉成员名不够，baseURL 必须真指 loopback server.port；
  port 0 占位符把 HTTP 层失败伪装成 REQUEST_FAILED，断言判别点错层（先踩后修）。
- **坑（同版本 tarball 重装）**：pnpm 对同名同版本 file: tgz 直接跳过——remove →
  rm node_modules 残留 → add 三步才算换包（S13 坑复现，3423 实操再证）。
- **坑（GUI 清 key 不清文件）**：Models 页清空 key + 保存后 `.credentials.yaml` 条目
  仍在——fake 键收尾必须物理清文件 + 终次重启（运行中实例内存持有旧值会回写）。
- **坑（nohup cwd）**：`cd` 进 scratch home 后 nohup 起宿主 CLI 必失败
  （ERR_MODULE_NOT_FOUND）——CLI 须从宿主仓 cwd 起；连续两次踩中。
