## 踩坑 / 经验

1. **限额下的角色隔离妥协与补救**：子 Agent 限额窗口期由主上下文先行机械取数（tarball 下载/diff），独立复核推翻两处初判（rc.2 已修 readonly-stack importer 站点；新传递依赖漏项）——「机械可先行、裁定必须独立」模式有效，须在记录中披露（本节即是）。
2. **假设式清单连计划文件都会犯**：阶段 2 实锤 plan 里写了一个不存在的文件名（settings.yaml）——生产已被 0.1.7 迁移改名 .imported；凡涉生产状态一律实测枚举。
3. **网络三态处置**：github SSH 间歇可用（tag 抢到+npm 抓窗成功）→ 重试编排器化（幂等+标记+日志入库）；npmjs 无 SSH 替代→纯等窗口。
4. **rc 线 peer 预检新语义**：app-boot includePrerelease 运行时可过但安装器默认 semver 判否——预发布枚举钉从「可选」变「安装期必需」。
5. 「Send behavior while busy=Queue」证实 S32 生产首测 Enter 不发送根因。
6. **拷配置别拷错文件名**：0.1.7 宿主找 settings.yaml 而非 .imported（拷错名=迁移腿静默不触发，链序落默认）。
