## 假设与验收标准（Spike 通道正本；结论三节在 session 记录）

| # | 假设（一句话） | 验收标准（实测什么） | 承接 |
|---|---|---|---|
| H1 | 外置 npm 包的 client half（`dsh.client.platform='web'` + `exports["./client"]`）经 profile 安装后可被 `/plugins/<pkg>/client.js` 分发加载，`ctx.slots.inject('settings.section', …)` 渲染设置页，`ctx.locale`/`ctx.remote` 可用 | spike web 实例（scratch `DSH_HOME` + 非 3080 端口）浏览器 DOM 断言：设置页出现 spike 卡片、文案经 locale 字典渲染；`/plugins` 分发请求 200；GO/NO-GO 定谳 | ADR-0006 |
| H2 | `dsh plugin --profile web add <本地目录>`（scratch `DSH_HOME` 下）端到端可复现：profile `package.json` dependencies 增加 + `dsh.profile.bundles` 自动追加（前提=包声明 `dsh.bundle.patch`）+ patch insert 行生效、Loader 加载无错；tarball 形态（pnpm pack 产物）等效 | 安装命令日志 + 三处落盘文件实测 + boot 日志零 load 错误；tarball 对比各一轮 | ADR-0007 |

| H4 | client half 经 `ctx.remote.credentials.set(ref, 伪值)` 写入后 `credentials.describe([ref])` 可见，`credentials/reference-updated` 事件到达 client，`unset` 后 describe 回落未配置 | 浏览器实测：卡片 key 输入伪值→保存→describe 返回（configured/writable/source）+ 事件到达证据→移除→describe 回落；落盘仅伪值 | ADR-0006（GO 的前提之一） |
| H5 | 包名/版本起点/交付形态（本地路径 / tarball / npm publish）可定谳且有实测依据 | ADR-0007 记录决策 + H2 实测对比证据 + （若选 npm 形态）`npm view` 名称可用性实测 | ADR-0007 |
