## 0. 范围与不做

**做（10 wire 参数 + 1 正确性修复 + 1 ADR）**：全局域名入口（searchIncludeDomains/searchExcludeDomains fan-out 三家 + 守卫）+ Tavily 3（chunksPerSource/filterByLanguage/includeDomainsMode）+ Exa 2（category/maxAgeHours）+ Firecrawl 3（news sources/categories/**search 面 timeout 修复**）。

**不做（显式边界，出处附录 A）**：
- **seam 阻挡**：include_raw_content / subpages / summary / scrapeOptions / maxAge（Firecrawl）——响应无槽或成本面（归 P3/P4 或 fetch 决策）
- **低价值/计费不可控**：auto_parameters（Tavily——不可预测升 depth 计费）/ safe / outputSchema 系
- **P3 候选**（本轮不做，附录留档）：Tavily exact_match / start_date / end_date / /extract 端点；Exa contents.text.verbosity/includeSections/additionalQueries(deep)；Firecrawl tbs 组合形态（sbd/cdr）
- **AnySearch**：上游契约面仅 query/max_results/zone（本地代码 anysearch.ts:134-149 + 官方 client 注释实证），无 P2 参数可加——zone 已覆盖地理语义，**零改动**（披露）
- DeepSeek：服务端工具参数面已齐（S14c host parity）

## 1. 设计决策（D1-D5）

**D1 全局域名入口（ADR-0018 正本，ADR-0015 同构模式）**：根 config 增 `searchIncludeDomains` / `searchExcludeDomains`（逗号分隔字符串，GUI 单输入框——与多 key 单槽同构）；**二选一硬约束——fail-loud 双路径正位（阶段 2 M-1 改判）**：①settings/GUI 路径 = 宿主 `installSection` 原生 `hooks.validate`（写队列内、persist **之前**跑——throw 拒绝本次写入并冒错给提交方；`attachSettingsSection` 增透传 validate + 拒写单测）——**弃用 resolveConfig throw**（宿主 watcher 同步 throw 被 `.then(()=>undefined, warn)` 吞成 warn + 已持久化非法值重启 brick 插件——实证链在阶段 2 审核报告）；②cordis.yml 路径 = resolveConfig throw → loader 加载面冒错（手动编辑文件场景的合理 loud）。fan-out：
- Tavily：`include_domains`（≤300）/`exclude_domains`（≤150）——split 后透传（超限由 API 4xx fail-loud，与 max_results 不 clamp 同构）；`include_domains_mode` 为 Tavily 成员级参数（D2）
- Exa：`includeDomains`/`excludeDomains`（≤1200，支持路径前缀/通配）；**守卫**：category ∈ {company, people} 时不发 excludeDomains（官方 400 组合限制——防御性跳过并 JSDoc 注明，非静默：不发该键与「未配置」等价）
- Firecrawl：`includeDomains`（二选一约束下 exclude 永不与之同发；hostname-only——URL-like 输入取 `host`；**通配守卫**：任一输入含 `*` 时 Firecrawl 整体跳过域名 fan-out〔hostname-only 不支持通配，防 400——与 Exa category 守卫同构的防御性跳过，ADR/JSDoc 注明；通配是 Exa 能力，附录 A 出处在档〕）
- AnySearch/DeepSeek：不映射

**D2 Tavily 成员级**：`chunksPerSource`（1-3，缺省不发=API 3；ultra-fast 不支持——配置时仍透传由 API 裁决？**否**——防御：depth=ultra-fast 时不发该键，JSDoc 注明）；`filterByLanguage`（bool 缺省 false；**守卫**：全局 searchLanguage 未设时不发——官方 400 前置）；`includeDomainsMode`（'filter'|'boost' 缺省不发=filter；守卫：include 域名未设时不发）。

**D3 Exa 成员级**：`category`（6 值枚举 + '' 清除哨兵；**守卫**：company/people 时不发 startPublishedDate——官方 400，防御跳过 + JSDoc）；`maxAgeHours`（-1..720 int，缺省不发——wire 嵌套在 **`contents.maxAgeHours`**〔exa.ts contents 构造点内〕；**现行官方名**，旧 livecrawl/crawlingOptions 已废弃勿采〔附录 A 漂移修正〕）。

**D4 Firecrawl 成员级 + 修复**：`sources`（config 枚举 `'web'|'news'|'web+news'`，缺省 **不发 sources 键**=API web 默认——零 wire 漂移口径钉死；显式配置时 wire `[{type:'news'}]` 或双项〔web+news 时双项〕；**响应映射**：data.news[]（title/snippet/url/date/imageUrl）→ WebSearchSource（date→publishedAt），**合并序 = web[] 先 news[] 后**；**limit 语义披露**〔ADR-0018〕：官方 limit 为**每 source** 上限——双 source 时结果上限 = 2×limit，透传不改）；`categories`（'developer'|'research'|'pdf' 单选 + '' 哨兵，wire `[{type}]`）；**search 面 `timeout: 20000` 显式**（P0 级修复：API 默认 60s vs 链预算 30s——同 S16-P0 scrape 修的同构缺口，search 面漏修）。

**D5 版本**：0.4.0→**0.5.0**（功能批 minor）+ UA×5 + 断言×5。config 零兼容问题（全新增字段，缺省不发零 wire 漂移——除 D4 timeout 修复〔有意行为变更，披露〕）。

## 5. 风险预案

- **组合限制漏守卫**：每条官方 400 组合限制（Exa category×date/excludeDomains、Tavily filter_by_language×language、ultra-fast×chunks）逐一入单测——漏一条即生产 400 降级链噪音。
- **news 响应字段实测偏差**：date/imageUrl 为 optional——tolerant 映射；有 key 后实测校正（firecrawl key 在池）。
- **全局域名二选一校验时点（双路径，见 D1 改判）**：settings/GUI = `hooks.validate` 在写队列 persist 之前拒写并冒错（用户刚提交立即看到）；cordis.yml = resolveConfig throw 在加载面冒错。resolveConfig throw **不得**作为 settings 路径的拒绝机制（宿主 watcher 吞 warn + 重启 brick，实证链在阶段 2 审核）。

## 附录 A — P2 参数核证正本（2026-09-10 双路调研；出处 URL 全量在调研报告随 audit-log 入档）

**Tavily**（docs.tavily.com/.../endpoint/search）：`chunks_per_source` 1-3 默认 3（仅 basic/advanced/fast；ultra-fast 每 URL 单条 NLP 摘要）；`include_domains` ≤300 / `exclude_domains` ≤150 + `include_domains_mode` filter|boost（默认 null=filter，须与 include 同用）；`include_raw_content` bool|'markdown'|'text'（**seam 无槽不做**）；`auto_parameters`（**不做**——自动升 depth 计 2 credits 不可控）；`filter_by_language`（要求 language 已设否则 400）。新增 P3 候选：exact_match/start_date/end_date（YYYY-MM-DD）/include_favicon//extract 端点（已增强，basic 1 credit/5 URL）。
**Exa**（exa.ai/docs/reference/search）：`category` 6 值（company/publication/news/personal site/financial report/people）；**company+people × startPublishedDate/endPublishedDate/excludeDomains = 400**；域名 ≤1200 支持 hostname/路径前缀/通配；`contents.maxAgeHours` -1..720（**现行名**——livecrawl deprecated、crawlingOptions/startCrawlDate/endCrawlDate 已废弃勿采）；subpages/summary（计费/复杂度不做）；P3 候选：text.verbosity/includeSections/additionalQueries（deep 系）。
**Firecrawl**（docs.firecrawl.dev/api-reference/search）：`sources` **对象数组** [{type}]，枚举 web|images|news（news 响应 data.news[]：title/snippet/url/date/imageUrl/position）；`categories` [{type}] developer|research|pdf；`includeDomains`/`excludeDomains` **互斥**（hostname-only 不带协议/路径）；`timeout` 顶层默认 60000（**vs 链 30s 预算——search 面漏修缺口**）；scrapeOptions/maxAge（成本不做）；P3 候选：tbs 组合形态（sbd:1/cdr 日期区间）。
**AnySearch**（本地 anysearch.ts:134-149 实读）：上游契约面 = query/max_results/zone 三参数（官方 client 注释 + 测试 :69-85 佐证）——**无 P2 参数可加，零改动**；地理语义已由 zone 覆盖；统一 searchLanguage/searchCountry 不消费（上游无对应参数——ADR-0015 已如实建模）。
