# ADR-0020: 版本线定档 v0.1.0

## Status

accepted（2026-09-12）

## Context

1. 项目内部开发编号已走到 0.9.0（Session 01–25 各批次递增），但从未对外发布；编号跨度虚高，与实际成熟度不匹配。
2. 定档批（S26）目标 = 生产部署就绪的规范化插件库：本地 git 规范化 + 推送个人远端的准备工作。

## Decision

1. **内部编号 0.2.0–0.9.0 归历史档**：各批次 CHANGELOG 条目保留原编号，不回改。
2. **正式版本线从 v0.1.0 起**：package.json / UA / 断言 / tag 全部以 0.1.0 为基。
3. **递进规则**：小补丁与细节迭代走补丁位（v0.1.0 → v0.1.1 → v0.1.2，标准 semver patch）；**仅特大架构功能扩展**升 minor（0.2.x）。细迭代节奏，不做大版本跨度开发。
4. 首个 v0.1.0 = S26 定档批终态；tag 为附注 tag，message 含定档说明。

## Consequences

- 后续每批次发版只需在补丁位 +1，除非变更同时满足「特大架构功能扩展」判据（届时 ADR 记录升级理由）。
- UA 字符串 `dsh-websearch/0.1.0` 与包版本同步维护（providers ×5 + 断言 ×5）。
