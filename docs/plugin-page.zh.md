# dsh-websearch（多源网页搜索）

把 Tavily、Exa、Firecrawl、AnySearch 和 DeepSeek 收进一条由你排序的搜索链：排在前面的成员失败时自动换下一个，每家可配多把 API key 轮换。启用后，Agent 的网页搜索与网页获取由本插件提供。

## 它做什么

| 成员 | 搜索 | 抓取 | 免费额度 |
|---|---|---|---|
| Tavily | 支持 | 支持 | 有 |
| Exa | 支持 | 不支持 | 有 |
| Firecrawl | 支持 | 支持 | 有 |
| AnySearch | 支持 | 支持 | 有 |
| DeepSeek（付费兜底） | 支持 | 不支持 | 无，默认不参与 |

- **搜索链降级**：按你排的顺序逐个尝试。成员没配 key、被停用，或者请求失败、超时，都跳到下一个；全部失败才报错，并给出每个成员的失败原因。
- **多 key 轮换**：一家可以填多把 key。某把失效时，先在同一家换 key 重试，再降级到下一家。
- **来源标注**：每次搜索和抓取的工具行上会标出实际由哪个成员提供服务。
- **DNS 韧性**：在解析受限的网络里，自动改用加密解析并预先探测线路；网络正常时不做任何改动。

## 设置项

位置：设置 → 网页搜索。修改从下一次搜索起生效。

- **成员卡**：为每家填 API key、启停成员、覆盖接口地址、调整该家的搜索参数。
- **搜索链**：调整成员的先后顺序，排在最前的是主搜索。
- **接管 web_fetch**：开启时，网页获取走本插件的云端抓取链；关闭时走本机直接抓取。
- **DNS 韧性**：开启、关闭，或保持自动。
- **详细配置**：兜底成员、超时、统一的搜索语言与地区等。

API key 只保存在你本机的凭据里；页面上只显示每家已配置的 key 数量。

## 接管与交还

- **启用本插件时**：插件页里官方的「网页搜索与获取」设置页隐藏，搜索与抓取使用哪个提供方由本插件决定。
- **关闭或卸载本插件时**：官方设置页自动恢复，搜索与抓取交回官方提供方。
- **一处例外**：如果你在旧版本里通过官方设置页把提供方选定为本插件的某个成员，这个选择保存在宿主层，优先级高于本插件，
  会绕过链序直连该成员、失败不降级。插件检测到它时，「网页搜索」设置页顶部会出现一张提示卡，点「清除钉值」即可一键清除
  （清除后由本插件链接管，关闭插件时官方提供方也能干净接管）。另外两条手动途径：
  - 关闭本插件后，在恢复出来的官方页里重新选择提供方并保存。搜索选「自动选择」、抓取选「本机直接获取」，即回到默认。
  - 或者关闭宿主，打开当前配置目录下的 `cordis.patch.yml`（桌面端是 `~/.dsh/profiles/desktop/`），把 `web` 行下的
    `searchProvider` 与 `fetchProvider` 两个键一起删掉，再启动宿主。

  用命令行卸载本插件不会清除这个选择。

## 关闭插件

用插件列表里 dsh-websearch 右侧的开关：它移除本插件对接管的全部设置，官方设置页随之恢复。
插件详情页里还有一个「启用组件 dsh-websearch」开关，它只停用插件本体，本插件对接管的设置原样保留。用它停用之后，
官方设置页仍然是隐藏的，设置里没有「网页搜索」一节，插件列表里却仍显示本插件已启用；列表里的开关关了再开也不会把它复位。
要恢复，回到详情页把这个开关打开。

## 兼容性

DSH 0.1.5-rc.1 到 0.2.x（含 0.2.2-rc.5）。在 0.1.5 与 0.1.6 的宿主上，启动时预计会多一条关于本插件补丁条目未命中的告警，可以忽略
（这两个版本线上没有实测过）。
