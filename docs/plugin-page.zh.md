# dsh-websearch（多源网页搜索）

> 多源搜索链接管 DSH 的网页搜索与获取：Tavily、Exa、Firecrawl、AnySearch 按你排的顺序自动降级，DeepSeek 付费兜底，每家可配多把 key 轮换。

- **高可用降级**：成员失败自动换下一个；多 key 池先同家换 key 再降级，全部失败才报错
- **统一配置**：语言、区域、域名黑白名单一处设置、全成员生效；工具行标注实际服务的成员
- **DNS 韧性**：受限网络自动加密解析，正常网络零改动
- **装即接管**：启用即接管官方「网页搜索与获取」，关闭即交回官方、设置保留
- **设置**：设置 → 网页搜索——成员卡填 key（只存本机）、拖动排序、web_fetch 与 DNS 开关，下次搜索即生效
- **兼容**：DSH 0.1.5-rc.1 至 0.2.x（含 0.2.2-rc.5）；旧宿主仅多一条无害补丁告警

问题反馈与版本发布：https://github.com/GeerMrc/dsh-websearch
