# dsh-websearch（多源网页搜索）

把 Tavily、Exa、Firecrawl、AnySearch 和 DeepSeek 收进一条由你排序的搜索链，接管 DSH 的网页搜索与网页获取。

## 主要功能与优势

| 成员 | 搜索 | 抓取 | 免费额度 |
|---|---|---|---|
| Tavily | 支持 | 支持 | 有 |
| Exa | 支持 | 不支持 | 有 |
| Firecrawl | 支持 | 支持 | 有 |
| AnySearch | 支持 | 支持 | 有 |
| DeepSeek（付费兜底） | 支持 | 不支持 | 无，默认不参与 |

- **高可用链**：成员失败自动换下一个，全部失败才报错；每家可配多把 key 轮换。
- **统一配置**：搜索语言、区域、域名黑白名单等一处配置、全成员生效。
- **来源透明**：每次搜索与抓取的工具行上标注实际服务的成员。
- **DNS 韧性**：受限网络自动切换加密解析，正常网络零改动。
- **装即接管**：启用后官方「网页搜索与获取」由本插件接管；关闭即交回官方。

## 安装与使用

- 安装后无需配置即可接管；在 设置 → 网页搜索 里为各成员填 API key（只存本机凭据，页面只显示数量）。
- 换包/升级后重启 DSH，或把插件关一次再开，新版本即生效。
- 设置修改从下一次搜索起生效，无需重启。

## 注意事项

- 关闭插件 = 官方搜索与抓取接管，本插件设置保留，重新启用即恢复。
- 插件详情页的「启用组件」开关只停用插件本体，会留下无设置入口的状态；恢复请回详情页打开它。
- 旧版本若在官方设置页保存过本插件成员，该选择需清除后链序才生效：关闭插件后在官方页重新选择保存，或在设置页顶部的一键清除提示卡处理。
- 用命令行卸载不会自动清除上述选择。

## 版本与兼容

- 当前版本见详情页「来源信息」；升级方式为先卸载再安装新版。
- 兼容 DSH 0.1.5-rc.1 至 0.2.x（含 0.2.2-rc.5）。0.1.5 与 0.1.6 宿主启动时会多一条无害的补丁告警。
