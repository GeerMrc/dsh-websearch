# dsh-websearch（多源网页搜索）

> 把 Tavily、Exa、Firecrawl、AnySearch 和 DeepSeek 收进一条由你排序的搜索链，接管 DSH 的网页搜索与网页获取：成员失败自动换下一个，每家可配多把 key 轮换。

## 它做什么

- **高可用链**：按你排的顺序逐个尝试，全部失败才报错；DeepSeek 付费兜底默认不参与
- **多 key 池**：一家多把 key，失效先同家换 key 再降级
- **统一参数**：搜索语言、区域、域名黑白名单一处配置、全成员生效
- **来源透明**：每次搜索与抓取的工具行标注实际服务的成员
- **DNS 韧性**：受限网络自动切换加密解析，正常网络零改动
- **装即接管**：启用后官方「网页搜索与获取」由本插件接管，关闭即交回官方

## 设置项

位置：设置 → 网页搜索。成员卡填 API key（只存本机凭据，页面只显示数量）；搜索链拖动排序；web_fetch 接管与 DNS 各一个开关。修改从下一次搜索起生效，无需重启。

## 关闭插件

**插件列表里的开关移除本插件对接管的全部设置**，官方搜索与抓取接管，重新启用即恢复。详情页的「启用组件」开关只停用插件本体（会留下无设置入口的状态），恢复请回详情页打开它。

## 兼容性

DSH 0.1.5-rc.1 至 0.2.x（含 0.2.2-rc.5）；0.1.5 与 0.1.6 宿主启动时会多一条无害的补丁告警。
